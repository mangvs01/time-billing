Validation

{% set excluded=summary.total-summary.importable-summary.overwrites %} {% if excluded %}

{% endif %} {% if summary.overwrites %}

{{summary.overwrites}} saisie(s) existante(s) seront écrasées par la valeur du classeur (corrections tracées). Un lot qui écrase des saisies ne peut pas être annulé en bloc : chaque écrasement se corrige depuis l'historique de la saisie.

La validation crée un lot identifiable, prend une sauvegarde SQLite vérifiée, puis insère toutes les lignes dans une seule transaction : en cas d'échec, rien n'est enregistré. Le lot reste annulable tant qu'aucune de ses prestations n'est couverte par une facture émise.

Modifications non enregistrées : cliquer sur « Enregistrer et recalculer » avant de valider.
